   # HBO Max, vežba izrade sajta

   Statički sajt rađen kao fakultetska vežba. Projekat nije povezan sa kompanijom HBO, a logo i posteri pripadaju njihovim vlasnicima i korišćeni su samo u edukativne svrhe.

   ## Tehnologije

   - HTML, CSS, JavaScript
   - jQuery i Vegas (slajder slika)

   ## Stranice

   - Početna
   - Filmovi (sa slajderom)
   - Serije
   - Registracija (forma sa validacijom unosa)

   ## Pokretanje

   Otvoriti `index.html` u browseru.
